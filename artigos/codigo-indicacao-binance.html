    O que é o código de indicação

    O código de indicação (também chamado de "código de convite" ou "referral code") é um mecanismo de divulgação que a Binance criou para recompensar quem indica a corretora para outras pessoas. Funciona assim:

    • Você, que está se cadastrando, digita um código no formulário de cadastro e passa a pagar menos taxa em cada compra e venda.
    • Quem te indicou (no caso, o CriptoTradey) recebe uma comissão da Binance por ter trazido um novo usuário.

    Na prática, é uma via de mão dupla: você ganha um desconto que não teria se cadastrasse sem código, e a gente recebe um incentivo por manter o conteúdo gratuito. Nenhum dos lados paga nada por isso — o custo é absorvido pela Binance.

    ⚠️ Transparência: quando você usa o código BN522, o CriptoTradey pode receber uma comissão da Binance. Isso não muda o desconto que você ganha nem o preço que você paga. Você pode, inclusive, usar qualquer outro código que tenha recebido de um amigo — o desconto funciona da mesma forma.

    Quanto você economiza, em números

    A taxa padrão de trading na Binance é de 0,1% por operação (essa é a taxa para quem opera no mercado à vista, o "spot"). Com um código de indicação, o desconto costuma ser de até 20%, o que reduz a taxa para 0,08%.

    Para quem faz uma compra pequena, a diferença parece irrelevante. Mas ela soma. Veja um exemplo:

    Volume negociado por mês Sem código (0,1%) Com BN522 (0,08%) Economia
    R$ 1.000R$ 1,00R$ 0,80R$ 0,20
    R$ 10.000R$ 10,00R$ 8,00R$ 2,00
    R$ 50.000R$ 50,00R$ 40,00R$ 10,00

    Dois detalhes importantes, para não criar expectativa errada:

    • O desconto é sobre a taxa de trading, não sobre saques, depósitos PIX (que já são gratuitos) ou outros produtos. Se você compra via "Comprar Cripto" com cartão, por exemplo, a taxa do cartão é outra coisa e não é afetada pelo código.
    • O percentual pode mudar. As campanhas da Binance mudam de tempos em tempos. O ideal é conferir os termos na tela de cadastro — se houver uma promoção ativa, ela aparece lá.

    Se o objetivo é reduzir custos, outra economia que vale conhecer é comprar USDT pelo mercado P2P da Binance, que não cobra taxa — veja como comprar USDT sem taxa.

    Onde inserir o código no cadastro

    O campo do código aparece no próprio formulário de cadastro, junto com e-mail e senha. É um campo pequeno, fácil de passar batido se você estiver com pressa. A ordem é esta:

    1. Na tela de cadastro, preencha o e-mail e a senha.
    2. Logo abaixo, procure o campo "Código de Indicação" ou "Referral ID". Ele pode vir marcado como opcional.
    3. Digite o código (por exemplo, BN522) e confirme que ele foi aceito — normalmente o campo deixa de mostrar erro quando o código é válido.
    4. Complete o cadastro normalmente: confirmação de e-mail, KYC e 2FA.

    Se você já passou da tela de cadastro sem digitar o código, não adianta procurar um lugar para colocar depois — não existe. Esse é o ponto que mais confunde quem se cadastra rápido demais. Detalhamos no final deste artigo o que fazer nesse caso.

    Para ver o passo a passo completo do cadastro, com o que ter em mãos antes de começar, leia o guia de como criar conta na Binance. Depois da conta pronta, o próximo passo é comprar criptomoedas com PIX.

    O código BN522

    O código que recomendamos aos leitores do CriptoTradey é o BN522. Ele funciona para contas novas criadas no site ou no app, para usuários no Brasil.

    Não é um "código secreto" nem tem validade para poucas pessoas — é um código de indicação comum, do tipo que qualquer corretora oferece. A diferença é que, ao usá-lo, você apoia diretamente o nosso trabalho de produzir este tipo de conteúdo gratuito, sem pagar nada a mais por isso.

    Se você prefere não usar código nenhum, tudo bem também: a conta funciona normalmente, você só não ganha o desconto nas taxas. A escolha é sua.

    Esqueci de usar o código: e agora?

    Essa é, de longe, a pergunta mais comum que recebemos. A resposta direta é: não dá para adicionar o código depois. A Binance não tem nenhuma tela de "inserir código de indicação" para contas já criadas, e o suporte não faz isso manualmente.

    Se você ainda não fez nenhuma operação (não depositou, não comprou, não sacou), a saída é simples: crie uma conta nova usando outro e-mail, e dessa vez digite o código na tela de cadastro. Você pode ter mais de uma conta por e-mail diferente, desde que cada uma passe pelo KYC.

    Se você já depositou ou fez trades, não vale a pena recomeçar só por causa do desconto — o trabalho de refazer o KYC e movimentar os fundos não compensa a economia. Nesse caso, o melhor é seguir usando a conta que você tem e, quando for indicar alguém, lembrar de avisar a pessoa para colocar o código desde o início.

    FAQ — Perguntas Frequentes

    Qual é o código de indicação da Binance em 2026?

    O código que recomendamos aos leitores do CriptoTradey é o BN522. Ele é inserido no campo "Código de Indicação" durante o cadastro.

    Quanto de desconto ganho com o código de indicação?

    Até 20% sobre as taxas de trading, dependendo da campanha vigente. Com a taxa padrão de 0,1%, o desconto de 20% a reduz para 0,08%.

    O desconto do código é vitalício?

    Na maioria das campanhas, sim — o desconto fica atrelado à conta. Mas confira os termos no momento do cadastro, pois podem mudar.

    Esqueci de usar o código, consigo adicionar depois?

    Não. A Binance não permite adicionar código em conta já criada. Se ainda não operou, crie uma conta nova com outro e-mail usando o código.

    O código funciona para contas existentes?

    Não. O código de indicação só vale para contas novas, no momento do cadastro.

    O código funciona no app e no site?

    Sim. O campo aparece no site (binance.com) e no app para Android e iOS, na tela de cadastro.
